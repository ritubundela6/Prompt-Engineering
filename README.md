## Author

## Project
Prompt engineering assignment: Kubernetes (K8s), Docker Swarm, and AWS Fargate (Serverless Containers).

## Objectives
- Compile a factual background sheet on architecture, scalability, setup requirements, and costs.
- Apply ERA: Expectation, Role, and Action.
- Audit the initial report through four CoVe stages and exactly four verification questions.
- Produce a corrected, source-grounded comparison while identifying unresolved claims.
- Deliver a 150-word executive summary and a transparently scored matrix.
- Document prompts and the REQ-003 / TR-002 audit trail.

## Deliverables
- `research_report.md`: background fact sheet, corrected report, four-step CoVe log, and official sources.
- `executive_summary.md`: exactly 150 words of summary prose; source note excluded from that count.
- `comparison_matrix.md`: scored Markdown table, rubric, assumptions, and limitations.
- `prompt_documentation.md`: ERA and CoVe templates, parameters, and execution mapping.
